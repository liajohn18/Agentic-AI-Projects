# Data folder

- `demo/` contains the synthetic bulk-upload dataset used by the dashboard and batch runner.
- `samples/` contains small individual examples for extraction and schema validation.
- `policies/` contains fictional policy material used by local retrieval.
- `aml_cases.db` is created locally when results are saved. It is ignored by Git and contains your local run history and review decisions; deleting it loses those saved results.

The customer, transaction, and policy content in this project is illustrative only. Do not put real customer or account data here.
