# Documentation guide

- `week3_project_documentation.md`: project overview, architecture, data, evaluation method, limitations, and run instructions.
- `week3_project_rubric_review_with_react.docx`: **current** Word rubric coverage review, including the bounded policy investigation loop.
- `public_demo_deployment.md`: steps and limitations for publishing the Streamlit demo.

The Word rubric review can be opened in Microsoft Word. It is a binary document and will look unreadable if opened as plain text in a code editor.
The `~$...docx` item shown while a Word file is open is a temporary lock file. Close the document in Word and it should disappear; do not use it as the report.
